# Matematické funkce
### Obsahuje
- Obsah Čtverce
- Obsah Obdélníku
- Obsah Kruhu
- Obsah Trojúhelníku
- Objem Krychle

## Jak používat
```txt
1. Vybrat jednotku a spočítat
2. Konec
```
> Vyberte akci (Konec ukončí program)
> Po vybrání program bude vyžadovat jednotku

```txt
1. mm
2. cm
3. dm
4. m
5. km
```

> Vyberte jednotku ve které si přejete počítat
> Po vybrání jednotky si vyberete co chete počítat

```txt
Vyberte tvar:
1. Čtverec
2. Obdelník
3. Kruh
4. Trojúhelník
5. Krychle (objem)
```

> Vyberete a následně pokračujte dle promptu.
